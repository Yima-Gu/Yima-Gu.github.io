# Yima Gu · Homepage

A small, dependency-free academic homepage for [yima-gu.github.io](https://yima-gu.github.io/).

## Structure

- `index.html` — biography, publications, education, and blog link
- `styles.css` — responsive layout
- `script.js` — mobile navigation and active section
- `assets/` — portrait and publication figures

GitHub Pages serves the files directly from the `main` branch root. Open `index.html` locally to preview; no build step is needed.

The portrait in `assets/portrait.jpg` was provided by Yima Gu.

Publication thumbnails come from the papers themselves:

- `assets/infodet-figure.jpg` is a resized copy of [InfoDet Figure 2](https://github.com/infodet2025/InfoDet/blob/main/assets/pipe.jpg), the dataset construction pipeline.
- `assets/dad-figure.jpg` shows the qualitative panels from [DAD Figure 1](https://arxiv.org/pdf/2609.07072), rendered and cropped from `figs/teaser.pdf` in the [paper's TeX source](https://arxiv.org/src/2609.07072).
